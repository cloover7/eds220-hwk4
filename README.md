## About

In 2025, the Eaton and Palisades fires ravaged the greater Los Angeles area at about the same time. This notebook contains an analysis on How the Eaton and Palisades fires affected vegetation, specifically using false color imagery to highlight vegetation differences inside and outside the fires' perimeters.

## Data

This project uses 3 datasets. Two are fire perimeter shapefiles from CAL FIRE. They are accessed [here](https://egis-lacounty.hub.arcgis.com/maps/lacounty::palisades-and-eaton-dissolved-fire-perimeters-2025/about). The third is a netCDF file of satellite data collected by Landsat 8. This data was retrieved from the [Microsoft Planetary Computer data catalog](https://planetarycomputer.microsoft.com/dataset/landsat-c2-l2) and can be accessed at the [course Google Drive](https://drive.google.com/drive/folders/1USqhiMLyN8GE05B8WJmHabviJGnmAsLP).
